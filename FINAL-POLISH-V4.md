# ORIEL V4 — Final interaction polish before real media

This pass intentionally avoids adding more spectacle for its own sake. It focuses on the details that make a luxury site feel finished.

## Search
- Persistent, unmistakable CLOSE pill in the top-right.
- ESC closes search.
- `/` or `Cmd/Ctrl + K` opens search from anywhere when the user is not typing.
- Clear-query action.
- Popular-search chips.
- Empty-result state.
- Product-result hover motion prepared for real campaign/product media.

## Navigation
- Menu button exposes its open state semantically.
- Search now advertises the keyboard shortcut.
- Existing editorial flyout remains the main desktop navigation language.
- Brand-hover light-surface behavior preserved.
- Mega-menu close action receives an explicit hover affordance.

## Home
- Added a discreet editorial chapter rail on desktop.
- It tracks the active section and allows chapter jumping.
- Hidden on smaller breakpoints so it never competes with content.

## Footer
- Newsletter now has a complete interaction state rather than being decorative.
- Added Back to top.
- Refined concierge/private-appointment affordances.
- Footer links now have consistent micro-interaction.

## Accessibility / finish
- Skip-to-content link.
- Focus-visible treatment.
- Reduced-motion system preserved.

## Next step
Do not add more UI before real media. Replace media slots with a coherent campaign system first, then tune animation timing against the actual footage.
