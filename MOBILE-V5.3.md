# ORIEL v5.3 — Mobile Experience

This pass preserves the approved desktop v5.2 experience and adds a dedicated mobile interaction model.

- Native touch scrolling on coarse-pointer/mobile devices (Lenis disabled there).
- Wardrobe becomes a horizontal scroll-snap rail on mobile; desktop keeps GSAP pinning.
- Worlds and Categories become thumb-friendly horizontal rails.
- Mobile search restored in the header.
- Header/menu, campaign deck, intro controls, product grids and touch targets refined.
- Collection, PDP, Editorial, Maison, Bag, Search and Footer receive mobile-specific spacing and sizing.
- Safe-area insets supported for modern iPhones.
- Desktop layout/animation rules remain unchanged outside mobile media queries.
